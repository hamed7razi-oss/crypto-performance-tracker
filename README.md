# Signal Radar — Crypto Performance Tracker

داشبورد و ردیاب خودکار عملکرد واقعی سیگنال‌های پروژه
[crypto-growth-screener](https://github.com/hamed7razi-oss/crypto-growth-screener).

⚠️ صرفاً برای بررسی دقت سیگنال‌ها؛ توصیه سرمایه‌گذاری نیست.

---

## این پروژه چیکار می‌کند

1. هر ۲ ساعت، سیگنال‌های تازه‌ی اسکرینر را مستقیماً از ریپوی آن می‌خواند (پوشه `signals/`).
2. کوین‌های تازه را به لیست پیگیری اضافه می‌کند؛ کوین‌های تکراری فقط شمارشگرشان بالا می‌رود
   (بدون سرمایه‌گذاری دوباره).
3. قیمت فعلی همه‌ی کوین‌های پیگیری‌شده (چه تازه چه قدیمی، حتی از روز اول) را می‌گیرد.
4. داده‌ها را در `data/` ذخیره و کامیت می‌کند.
5. یک پیام کوتاه وضعیت به تلگرام می‌فرستد.
6. صفحه `index.html` (میزبانی‌شده روی GitHub Pages) مستقیماً از همین داده‌ها
   نمودارهای تعاملی می‌سازد — بدون نیاز به تلگرام برای دیدن جزئیات.

---

## پیش‌نیاز: تغییرات لازم در ریپوی اسکرینر

قبل از راه‌اندازی این پروژه، باید دو فایل در ریپوی `crypto-growth-screener` آپدیت شوند
(فایل‌های آماده در پیام کلود داده شده):
- `screener.py` (نسخه‌ی جدید که در پوشه `signals/` اسنپ‌شات ذخیره می‌کند)
- `.github/workflows/run.yml` (نسخه‌ی جدید که این پوشه را کامیت می‌کند)

## راه‌اندازی این پروژه (مرحله به مرحله)

### ۱. ساخت بات تلگرام جدید و مجزا
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. `/newbot` → یک نام و یوزرنیم جدید انتخاب کن (متفاوت از بات اسکرینر).
3. توکن را نگه دار.
4. طبق همان روش قبلی (پیام به بات + آدرس `getUpdates`)، Chat ID را پیدا کن.

### ۲. ساخت ریپازیتوری جدید
یک ریپوی عمومی (Public) جدید بساز، مثلاً با نام `crypto-performance-tracker`.
**نکته:** باید Public باشد تا GitHub Pages رایگان روی آن فعال شود.

### ۳. آپلود فایل‌ها
فایل‌های زیر را در همین ساختار آپلود کن:
```
crypto-performance-tracker/
├── tracker.py
├── requirements.txt
├── index.html
├── README.md
└── .github/
    └── workflows/
        └── tracker.yml
```

### ۴. تنظیم Secrets
`Settings → Secrets and variables → Actions → New repository secret`:
| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن بات جدید |
| `TELEGRAM_CHAT_ID` | Chat ID جدید |

### ۵. فعال‌سازی GitHub Pages
`Settings → Pages` → زیر «Build and deployment» → Source را روی
**Deploy from a branch** بگذار → Branch: `main`، پوشه: `/ (root)` → Save.

بعد از چند دقیقه، آدرس داشبورد فعال می‌شود:
```
https://hamed7razi-oss.github.io/crypto-performance-tracker/
```

### ۶. اجرای دستی اول
`Actions` → workflow با نام **Crypto Performance Tracker** → **Run workflow**.

اولین اجرا فقط داده پایه را ثبت می‌کند (بدون نمودار کامل، چون به حداقل ۲ نقطه
زمانی نیاز است). از اجرای دوم به بعد (۲ ساعت بعد یا اجرای دستی مجدد)، داشبورد
کامل می‌شود.

## محدودیت‌ها

- اگر ریپوی اسکرینر پرایوت (Private) باشد، این پروژه نمی‌تواند فایل‌های
  `signals/` را بخواند (API عمومی گیت‌هاب فقط روی ریپوی Public کار می‌کند).
- کوین‌هایی که در CoinGecko پیدا نشوند (نماد نامعتبر یا خیلی نو) نادیده گرفته می‌شوند.
